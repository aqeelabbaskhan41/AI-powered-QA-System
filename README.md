#  AI-powered Question Answering System
A full-stack mern QA system where I first used my own trained RNN(LSTM) on thousand question &amp; answers but it was limited so I used LLM for make it more generlized.

An advanced **full-stack MERN project** that provides a powerful **Question-Answering (QA) system** with **two backend implementations**:  
1. A **deep learning model(PyTorch ONNIX)** built with **RNN and LSTM**, trained on thousands of general QA pairs.  
2. A **fine-tuned (Meta-Llama-3.1-8B-Instruct-Turbo) model**, enabling more **flexible, context-aware, and natural responses**.  

This project demonstrates the integration of **custom ML models** and **state-of-the-art LLMs** into a web-based platform with a **user-friendly frontend** and **scalable backend**.

---

## 🚀 Features
-  **Full-stack MERN architecture** (Express.js, React.js, Node.js)  
-  **Custom Deep Learning Model** (RNN + LSTM) for QA (but was limited) 
-  **Fine-tuned LLaMA backend** for advanced responses (meta-llama/Meta-Llama-3.1-8B-Instruct-Turbo)  
-  **RESTful API** for model integration  
-  **Interactive React Frontend** for asking questions  
-  **Scalable backend** for future model integrations  
-  Secure environment setup using `.env`
